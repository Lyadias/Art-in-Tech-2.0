Art in Tech 2.0

Sobre o projeto

O Art in Tech 2.0 é uma plataforma desenvolvida como projeto acadêmico do curso Técnico em Informática para Internet do Instituto Federal do Maranhão (IFMA).

O projeto tem como objetivo criar um ambiente onde artistas possam divulgar seus trabalhos, compartilhar experiências e interagir com pessoas interessadas em arte. A plataforma reúne criatividade e tecnologia, oferecendo uma interface moderna, intuitiva e acessível.

---

Funcionalidades

- Cadastro de usuários
- Login de usuários
- Perfil personalizado
- Alteração de foto de perfil
- Alteração do nome de usuário (@)
- Feed de publicações
- Criação de postagens
- Sistema de curtidas
- Sistema de comentários
- Navegação entre páginas
- Interface responsiva
- Integração com banco de dados

Como executar o projeto

1. Clone o repositório:

git clone https://github.com/Lyadias/Art-in-Tech-2.0.git

2. Abra a pasta do projeto.

3. Inicie um servidor local, como XAMPP ou WAMP.

4. Importe o banco de dados MySQL.

5. Configure o arquivo de conexão com o banco de dados.

6. Execute o projeto pelo navegador.

---

Objetivo

O Art in Tech 2.0 foi desenvolvido com a finalidade de incentivar a divulgação da arte por meio da tecnologia, proporcionando um espaço onde artistas possam compartilhar seus trabalhos e usuários possam descobrir novos criadores de forma simples e organizada.
